What changed from v2:
  • Row card wraps everything. All slabs (including the add-player button) sit inside the same outer container with consistent gaps. Button reads as part of the row, not floating beside it.
  • No more red tint on filter slabs — color was adding confusion, not clarity.
  • Filter constraints use a verb-caption / noun-value pattern: "Drafted Outside / 1st Round" and "Not Drafted By / Eagles." Caption carries the question, value carries the answer. Each slab reads as a sentence on its own.
  • Added Variant 4 to show the "not drafted by [team]" case using the same pattern.
Mobile (≤ 600px):
  • Time and Position sit side-by-side on the first line, filter (if present) spans full width on the second line, button spans full width on the bottom.
  • Everything stays inside the row card so the visual cohesion holds at small widths too.
